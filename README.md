# Лекало — цифровой дизайнер презентаций

Сервис принимает корпоративный шаблон `.pptx` и бриф. Шаблон он разбирает на дизайн-систему: палитру, гарнитуры, шкалу кеглей, сетку, холсты и собственные композиции шаблона. По брифу пишет сценарий и тексты, затем собирает **три варианта** колоды в стиле шаблона:

- A — классический;
- B — визуальный;
- C — компактный.

Каждый слайд проходит встроенный аудит: 26 детерминированных проверок и 11 контекстных через VLM. Пользователь сам выбирает, какие замечания исправить. Экспорт — нативный PPTX (тексты, таблицы и диаграммы редактируются), PDF и HTML.

Интерфейс работает в браузере на десктопе и как мини-приложение ВКонтакте (vk-bridge: тема, скачивание, «поделиться»).

| | |
|---|---|
| Время на три колоды | 25–80 с без иллюстраций, ~2 мин с иллюстрациями (лимит ТЗ — 5 мин) |
| Модели | Qwen3.6-35B-A3B (Apache 2.0) — текст и VLM; gpt-oss-20b (Apache 2.0) — запасная; GigaChat / Kandinsky — иллюстрации |
| Шаблоны | любые `.pptx`, в том числе незнакомые и растровые (слайды-картинки из Figma/Canva) |

Подробности: [архитектура](docs/ARCHITECTURE.md) · [модели](docs/MODELS.md) · [аудит](docs/AUDIT.md).

## Быстрый старт

### Docker

```bash
cp .env.example .env        # впишите ключи
docker compose up --build   # http://localhost:8000
```

Образ включает LibreOffice и базовые шрифты с кириллицей. Данные (профили шаблонов, проекты, кэш) хранятся в `./data`.

### Локально (Windows / Linux / macOS)

Нужны Python 3.12, Node 20 и LibreOffice (`soffice`; путь можно задать в `SOFFICE_PATH`).

```bash
pip install -r backend/requirements.txt
npm --prefix frontend ci && npm --prefix frontend run build
python -m uvicorn app.api.main:app --app-dir backend --port 8000
```

Для разработки фронтенда: `npm --prefix frontend run dev` (http://localhost:5173, API проксируется на :8000).

### Ключи (`.env`)

| Переменная | Назначение |
|---|---|
| `LLM_API_KEY`, `LLM_FOLDER_ID` | Yandex Cloud AI Studio (OpenAI-совместимый API) — Qwen3.6-35B-A3B и gpt-oss-20b |
| `GIGACHAT_AUTH_KEY`, `GIGACHAT_SCOPE` | GigaChat (генерация иллюстраций через Kandinsky). Без ключа колоды собираются без картинок |
| `DATA_DIR`, `SOFFICE_PATH` | необязательно: каталог данных и путь к LibreOffice |

Секреты хранятся только в `.env`, он в `.gitignore`. Всё остальное, что влияет на результат, — в [`config.yaml`](config.yaml):

- модели и конкурентность;
- дедлайн 300 с;
- описание трёх вариантов;
- пороги аудита;
- активные версии скиллов.

## Командная строка (воспроизводимый прогон)

```bash
cd backend
python -m app.cli parse ../path/template.pptx                 # разбор шаблона → data/templates/<sha>/profile.json
python -m app.cli generate --template ../path/template.pptx --brief ../examples/brief_feature.yaml
python -m app.cli generate --template <id> --content tests/fixtures/demo_content.json   # без планировщика
```

Все параметры запуска задаются в `config.yaml` и файле брифа (примеры — в `examples/`). Каждый прогон пишет в `data/jobs/<id>/`:

- `content.json` — сценарий;
- по каждому варианту: `plan.json`, `layouts.json`, `audit.json`, PPTX/PDF/HTML;
- `llm_trace.jsonl` — все вызовы моделей с версиями скиллов.

## Тесты

```bash
cd backend && python -m pytest tests -q
```

**Модульные тесты:**
- цвета и WCAG-контраст;
- запись текста с сохранением форматирования шаблона;
- подбор кегля;
- распознавание групп карточек (с подложками и без);
- аппроксимация фона растровых шаблонов;
- фильтры контекстного аудита;
- сверка чисел сценария с брифом;
- восстановление зависших задач.

**Интеграционные тесты:** синтетический шаблон → профиль → три варианта на фиксированном плане → рендер LibreOffice → детерминированный аудит без ошибок вёрстки. Интеграционные тесты пропускаются без LibreOffice. Реальные шаблоны из `data/templates` проверяются, если они загружены.

## Структура

```
backend/app/
  parsing/   разбор шаблона: OOXML, шрифты, рендер, анализ слайдов, токены, холсты, паттерны, растровые шаблоны
  planning/  бриф → контент-модель (LLM), три варианта вёрстки
  layout/    композер рецептов, заполнение паттернов шаблона, подбор кегля, иконки, иллюстрации, сборка PPTX
  audit/     детерминированные и контекстные проверки, исправления
  export/    HTML-просмотрщик
  llm/       OpenAI-совместимый клиент, реестр скиллов
  pipeline.py, api/main.py, cli.py
backend/skills/<name>/<version>.yaml   промпты-скиллы (версионируются, активная версия — в config.yaml)
backend/assets/icons/lucide            иконки (ISC)
frontend/                              React 19 + Vite + Tailwind 4, токены VKUI, vk-bridge
docs/                                  ARCHITECTURE, MODELS, AUDIT
```

## Ограничения

- **Проверено в LibreOffice, но не в PowerPoint.** Метрики текста считаются по реальным шрифтам шаблона. Если у шрифта нет кириллицы, измерение идёт по запасному шрифту рендерера, и в PowerPoint отрисовка может немного отличаться.
- **Цифры и факты берутся только из брифа.** Если данных мало, модель может обобщать. Такие места аудит помечает проверкой `facts_supported`, их можно исправить автоматически.
- **Растровые шаблоны восстанавливаются приближённо.** Переносятся фон, типографика, карточки и цвета. Логотипы и картинки исходника в новые колоды не попадают.
- **Иллюстрации генерируются по одной.** Личный тариф GigaChat не принимает параллельные запросы, поэтому на картинку уходит ~20–50 с.
