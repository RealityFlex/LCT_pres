# Модели

Все модели — с открытыми весами, не больше 35B параметров, под лицензией Apache 2.0. В прототипе они вызываются через облачный OpenAI-совместимый API. Провайдер задаётся в `config.yaml` (`llm.base_url`, `*_model`), поэтому переход на собственный инференс (vLLM или инференс VK) — это смена конфигурации, а не кода.

| Роль | Модель | Параметры | Лицензия | Где используется |
|---|---|---|---|---|
| Текст (основная) | [Qwen3.6-35B-A3B](https://huggingface.co/Qwen/Qwen3.6-35B-A3B) | 35B всего, ~3B активных (MoE) | [Apache 2.0](https://huggingface.co/Qwen/Qwen3.6-35B-A3B/blob/main/LICENSE) | сценарий (`deck_planner`), сокращение текста (`text_condenser`), исправления (`fixer`), ревью колоды (`deck_auditor`) |
| VLM | Qwen3.6-35B-A3B (мультимодальная) | то же | Apache 2.0 | описание стиля шаблона (`template_analyst`), контекстный аудит слайдов по картинке (`slide_auditor`) |
| Текст (запасная) | [gpt-oss-20b](https://huggingface.co/openai/gpt-oss-20b) | 21B (MoE) | Apache 2.0 | автоматически, если основная модель не ответила или вернула невалидный JSON |
| Иллюстрации | Kandinsky через GigaChat API ([Kandinsky 3.1](https://huggingface.co/ai-forever/Kandinsky3.1), [Kandinsky 3.0](https://huggingface.co/kandinsky-community/kandinsky-3)) | — | Apache 2.0 (веса Kandinsky 3.x) | генерация иллюстраций в стиле шаблона |

## Почему так

- **Qwen3.6-35B-A3B.** Одна модель закрывает и текст, и зрение: VLM-разметка шаблона и аудит по картинке идут тем же endpoint. MoE с ~3B активных параметров отвечает за 1–2 с, поэтому 30–70 вызовов на три колоды укладываются в 5 минут. Режим размышлений отключён через `chat_template_kwargs.enable_thinking=false`: для структурированного JSON он не нужен и только съедает время.
- **gpt-oss-20b** — страховка от сбоев и таймаутов основной модели. Той же лицензии и размера хватает для сокращения текста и ревью.
- **Kandinsky.** В прототипе он вызывается через GigaChat API, это хостинговый сервис Сбера с собственными условиями использования. Для полностью открытого контура его заменяют развёрнутые у себя веса Kandinsky 3.x (Apache 2.0): интерфейс генератора изолирован в `backend/app/layout/images.py`. Без ключа GigaChat колоды собираются без иллюстраций.

## Как модели встроены

- **Клиент** (`backend/app/llm/client.py`):
  - асинхронный OpenAI-совместимый клиент;
  - семафор конкурентности (`llm.max_concurrency`);
  - таймауты, повторы и переключение на запасную модель;
  - извлечение и починка JSON из ответа;
  - трасса всех вызовов в `data/jobs/<id>/llm_trace.jsonl`: скилл, версия, хэш промпта, модель, время, токены.
- **Скиллы** (`backend/skills/<name>/<version>.yaml`): системный и пользовательский промпты с подстановкой `{{переменных}}`, температура, лимит токенов. Активные версии перечислены в `config.yaml → skills`, их список и описания показывает страница «Система».
- **Детерминизм прежде модели:**
  - все размеры, цвета, шрифты и геометрия вычисляются без моделей;
  - модели пишут текст, описывают стиль и оценивают смысл.

  Поэтому сбой модели не ломает вёрстку. Разбор шаблона без VLM остаётся полным, а колода без контекстного аудита всё равно собирается и проверяется детерминированно.
